同济校园活动与竞赛日历。可按学院查询报名时间、比赛阶段、奖学金申报与校园活动，也可单独查看学院的评审文件、推荐赛事和校级竞赛目录。[访问日历](https://events.hachile.org/)

## 使用日历

- 在「活动日历」按月份、日期、学院、类别、节点或关键词查询。选择学院后可勾选同时展示面向全校或公开报名的活动。
- 在「学院竞赛目录」选择院系和目录范围，查看来源及关联日程。部分院系有本科和研究生两种口径，条目中注明了适用对象。
- 收藏保存在当前浏览器。可将当前筛选或收藏的日程导出为 ICS，也可在系统日历中添加订阅。订阅客户端按自己的刷新频率获取后续编辑。[全站 ICS](https://events.hachile.org/calendar.ics)

## 数据依据

截至 2026 年 11 月 25 日，本站收录 31 个院系和校内单位、478 条目录记录，以及 71 个有明确日期的节点。其中 59 个为竞赛日程，8 个为奖学金节点，4 个为校园活动。一个赛事可按不同报名及比赛阶段形成多条日程，也可对应多个学院的目录记录。

| 资料 | 本站如何使用 |
| --- | --- |
| 学院奖学金通知、评定办法及附件 | 保留适用年度、对象和审定范围，附回原文的入口。 |
| 国豪书院 2025 年 6 月 9 日印发的附件 2 | 按提供的名单整理 73 项赛事和系数；同时提供书院另行公布的推荐目录。 |
| 同济大学本科生学科竞赛目录（2026 版） | 按责任单位索引 255 项赛事。多单位负责的赛事可从各责任单位查到。 |
| 同济院系或赛事主办方通知 | 把报名、交件、比赛等阶段分别记入日历。仅有月份或尚未核实日期的赛事可在目录里查询。 |

具体学年的奖学金认定由学院审核。日程中的明确时刻统一显示北京时间，全天活动按通知的日历日期记录。新届次需独立核实。[同济校级竞赛目录](https://ghc.tongji.edu.cn/__local/6/44/4F/BC7220220700B3281CCE6799E4B_0205F811_3CFEB.pdf) / [国豪书院官网](https://ghc.tongji.edu.cn/info/1221/6017.htm)

## 本地运行

在仓库根目录启动静态服务器，然后打开 `http://localhost:8000/`。

```sh
python -m http.server 8000
```

## 维护与纠错

在 `data.json` 中维护 `colleges`（院系和依据）、`catalog`（目录条目）及 `events`（日程）。通过稳定的 `id`、`college` 和 `catalogIds` 关联。校内选拔与全国赛、学生截止与高校报送截止应分别写明。日期使用 `YYYY-MM-DD`，精确到时分的节点使用带 `+08:00` 的 ISO 时间；全天区间的结束日期包含当天。

更新 `updated`，使用 Node.js 运行以下命令。第一条校验数据并生成全站订阅，第二条验证仓库内的订阅内容与日程一致。GitHub Pages 从 `main` 的根目录发布。

```sh
node tools/calendar.mjs
node tools/calendar.mjs --check
```

反馈时请附上学校、学院或主办方的通知原文，注明届次、适用人群及需要更改的日期。[提交活动或纠错](https://github.com/GPDdev/events.hachile.org/issues/new)
